261019 복습

hn: 제목 태그(1~6까지 있음)
p: 문단 태그

blockquote: 인용문 태그 코드 내에서 줄바꿈만 하면 적용 X(br 태그 활용해야 함) 
            pre: 공백이나           줄바꿈을 
            표현하는 태그

strong 태그: 텍스트 강조 태그1
b 태그: 텍스트 강조 태그2

em 태그: 이텔릭 / 흐름상 강조할 때 쓰는 태그
i 태그: 단순 이텔릭 태그

q 태그: 줄바꿈이 없는 인용 태그(따옴표가 추가됨)
mark 태그: 형광펜 배경색 효과 태그(노란색 고정)

div 태그: 줄을 바꾸어 하나의 독립된 단락/ 블록으로 묶을 때 쓰는 태그
span 태그: 줄 안에서 인라인으로 묶기
  • ul 태그: 순서 없는 목록
    • li 태그 안에 리스트를 또 넣을 수 있음
  • li 태그: 목록 리스트
  1. ol 태그: 순서 있는 목록
    1. ol 태그는 type 값과 start 값으로 리스트 숫자 조정 가능
  2. li 태그: 목록 리스트
dl 태그: 제목과 설명 텍스트로 표현하는 목록
dt 태그: 제목 텍스트
dd 태그: 설명 텍스트
table 태그 표를 생성하는 태그
tr 태그 표의 행을 생성하는 태그
th 태그 셀 내에 제목에 해당하는 표의 열 태그
td 태그 셀 내에 내용을 입력하는 표의 열 태그
